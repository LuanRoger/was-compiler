# Domain docs

## Before exploring

This repository uses a single-context layout:

- Read `GLOSSARY.md` at the repository root when present.
- Read decisions in `docs/adr/` relevant to the area being explored.

If these documents are absent, proceed silently. The domain-modeling
skill creates them lazily when terminology or decisions are resolved.

## Vocabulary

Use glossary terms when naming concepts in issues, proposals,
hypotheses, and tests. If a needed concept is missing, reconsider
the terminology or note the gap for domain-modeling.

## Decisions

Surface conflicts with existing ADRs explicitly, identifying the ADR
and explaining why its decision may need to be reopened.
